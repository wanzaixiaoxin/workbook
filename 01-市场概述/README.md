## 核心要点速览

### 什么是银行间债券市场？

银行间债券市场是中国债券市场的核心组成部分，成立于1997年，是金融机构之间进行债券买卖、回购等交易的市场。与交易所债券市场相比，银行间债券市场具有以下特征：

- **场外市场（OTC）**：采用询价交易模式，非集中撮合
- **大宗交易为主**：单笔交易金额大，机构投资者为主
- **做市商制度**：通过做市商提供流动性
- **托管结算集中**：统一通过中债登/上清所进行托管结算

### 市场地位

- 银行间债券市场占中国债券市场总规模约 **85%** 以上
- 是中国金融体系最重要的直接融资渠道之一
- 是央行公开市场操作和货币政策传导的重要平台
