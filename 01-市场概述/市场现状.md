# 银行间债券市场现状

> 最后更新：2026-03-30

## 一、市场规模

### 债券托管总量

中国债券市场托管总量已突破 **150 万亿元**，其中银行间债券市场托管量占比超过 85%。

### 主要债券品种规模（参考）

| 品种 | 发行主体 | 规模占比（约） | 说明 |
|------|----------|----------------|------|
| 国债 | 财政部 | ~20% | 无风险利率基准 |
| 政策性金融债 | 政策性银行 | ~25% | 准主权信用 |
| 同业存单（NCD） | 商业银行 | ~15% | 短期流动性工具 |
| 商业银行债 | 商业银行 | ~5% | 含二级资本债、永续债 |
| 非金融企业债务融资工具 | 非金融企业 | ~15% | 中票、短融、超短融等 |
| 企业债 | 企业（发改委审批） | ~5% | 城投债为主 |
| 公司债 | 上市公司（证监会审批） | ~8% | 公募/私募 |
| 地方政府债 | 地方政府 | ~7% | 置换债+新增债 |

> **注意**：以上比例为大致参考，实际数据请以中国债券信息网（chinabond.com.cn）最新统计为准。

## 二、市场结构

### 交易场所

```
中国债券市场
├── 银行间债券市场（主导）
│   ├── 中国外汇交易中心（CFETS）—— 交易平台
│   ├── 中债登（CCDC）—— 托管结算（政府债、企业债等）
│   └── 上清所（SHCH）—— 托管结算（金融债、短融中票等）
├── 交易所债券市场
│   ├── 上交所（SSE）
│   └── 深交所（SZSE）
└── 商业银行柜台市场
    └── 面向个人和中小投资者
```

### 交易方式

| 交易方式 | 说明 | 特点 |
|----------|------|------|
| 现券买卖 | 一方出售、另一方购买债券 | 最基础交易方式 |
| 质押式回购 | 以债券为质押进行短期融资 | 市场交易量最大 |
| 买断式回购 | 债券所有权转移的回购 | 较少使用 |
| 债券借贷 | 借入债券并承诺归还 | 做空机制 |
| 债券远期 | 约定未来日期买卖债券 | 衍生品 |
| 利率互换 | 基于债券的利率互换交易 | 衍生品 |

### 交易机制

- **询价交易**：双方协商确定价格，为银行间市场主要交易方式
- **做市商制度**：做市商持续提供双边报价，维持市场流动性
- **点击成交**：对手方直接接受做市商报价成交
- **请求报价（RFQ）**：向多个做市商请求报价，择优成交

## 三、发展趋势

### 1. 市场化改革持续深化

- 利率市场化推进，债券收益率曲线日趋完善
- 信用债违约趋于常态化，信用定价更加市场化
- 衍生品品种不断丰富（国债期货、利率互换等）

### 2. 对外开放加速

- 境外机构投资渠道持续拓宽（CIBM Direct、Bond Connect）
- 中国债券纳入全球主要指数（彭博巴克莱、JP摩根）
- 境外机构持有比例逐步提升

### 3. 金融科技渗透

- 电子化交易平台升级（FICC一体化）
- AI/机器学习应用于交易策略与风控
- 区块链技术在发行、托管环节的探索
- FIX协议标准化推进，直通式处理（STP）

### 4. 监管趋严与规范

- 统一监管框架逐步形成（资管新规等）
- 交易行为监控加强
- 反洗钱与合规要求提升
