# 银行间债券市场现状

> 最后更新：2026-04-02

## 一、市场规模

中国债券市场托管余额稳居全球第二位，其中银行间及柜台市场托管量占比约 **88%**，交易所市场占比约12%。

> 数据来源：中国人民银行。

## 二、市场结构

### 交易场所

```
中国债券市场
├── 银行间债券市场（主导，占85%以上）
│   ├── 中国外汇交易中心（CFETS）—— 交易平台
│   ├── 中债登（CCDC）—— 托管结算（政府债、企业债等）
│   └── 上清所（SHCH）—— 托管结算（金融债、短融中票等）
├── 交易所债券市场
│   ├── 上交所（SSE）
│   └── 深交所（SZSE）
└── 商业银行柜台市场
    └── 面向个人和中小投资者
```

### 交易方式

| 交易方式 | 说明 | 特点 |
|----------|------|------|
| 现券买卖 | 一方出售、另一方购买债券 | 最基础交易方式 |
| 质押式回购 | 以债券为质押进行短期融资 | 市场交易量最大 |
| 买断式回购 | 债券所有权转移的回购 | 较少使用 |
| 债券借贷 | 借入债券并承诺归还 | 做空机制 |
| 债券远期 | 约定未来日期买卖债券 | 衍生品 |
| 利率互换 | 基于债券的利率互换交易 | 衍生品 |

### 交易机制

- **询价交易**：双方协商确定价格，为银行间市场主要交易方式
- **做市商制度**：做市商持续提供双边报价，维持市场流动性
- **点击成交**：对手方直接接受做市商报价成交
- **请求报价（RFQ）**：向多个做市商请求报价，择优成交

## 三、主要债券品种

| 品种 | 发行主体 | 说明 |
|------|----------|------|
| 国债 | 财政部 | 无风险利率基准 |
| 地方政府债 | 地方政府 | 专项债+一般债 |
| 政策性金融债 | 政策性银行 | 准主权信用 |
| 同业存单（NCD） | 商业银行 | 短期流动性工具 |
| 非金融企业债务融资工具 | 非金融企业 | 中票、短融、超短融等 |
| 公司债 | 上市公司（证监会审核） | 公募/私募 |
| 商业银行债 | 商业银行 | 含二级资本债、永续债 |
| 企业债 | 企业（证监会审核） | 城投债为主 |
