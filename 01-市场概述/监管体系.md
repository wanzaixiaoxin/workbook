# 监管体系

> 最后更新：2026-03-30

## 一、监管机构概览

### 核心监管机构

| 机构 | 职责范围 | 对债券市场的影响 |
|------|----------|------------------|
| **中国人民银行（PBOC）** | 银行间债券市场监管、货币政策 | 市场准入、交易规则、公开市场操作 |
| **国家金融监督管理总局（NFRA）** | 银行保险业监管 | 金融机构投资行为监管 |
| **中国证监会（CSRC）** | 证券期货市场监管 | 交易所债券市场、公司债 |
| **国家发改委（NDRC）** | 企业债发行审批 | 企业债发行额度与条件 |
| **财政部（MOF）** | 国债发行管理 | 国债发行计划与制度 |
| **国家外汇管理局（SAFE）** | 外汇管理 | 境外机构投资债券市场的外汇管理 |

### 基础设施机构（自律管理）

| 机构 | 性质 | 管理职能 |
|------|------|----------|
| **中国外汇交易中心（CFETS）** | 央行直属 | 交易平台运营、交易规则制定 |
| **中央结算公司（CCDC/中债登）** | 央行管理 | 托管结算、估值发布 |
| **银行间市场清算所（SHCH/上清所）** | 央行管理 | 托管结算、集中清算 |
| **交易商协会（NAFMII）** | 自律组织 | 非金融企业债务融资工具注册管理 |
| **上交所/深交所** | 证监会管理 | 交易所债券市场监管 |

## 二、监管框架

### 债券发行监管

```
债券发行监管框架
├── 国债 —— 财政部审批发行
├── 地方政府债 —— 财政部限额管理
├── 政策性金融债 —— 央行审批
├── 商业银行债 —— NFRA + 央行审批
├── 非金融企业债务融资工具 —— 交易商协会注册
│   ├── 短期融资券（CP）
│   ├── 超短期融资券（SCP）
│   ├── 中期票据（MTN）
│   ├── 定向债务融资工具（PPN）
│   └── 资产支持票据（ABN）
├── 企业债 —— 证监会/发改委审核
├── 公司债 —— 证监会审核
│   ├── 公开发行（大公募/小公募）
│   └── 非公开发行（私募债）
└── 金融债 —— 央行审批
```

### 交易监管

**央行监管重点**：
- 银行间债券市场准入管理
- 交易行为规范（禁止利益输送、操纵市场）
- 做市商管理
- 回购交易管理（质押率、集中度等）

**自律管理（CFETS/NAFMII）**：
- 交易规则制定与执行
- 异常交易监控
- 做市商评价
- 市场监测报告

### 投资者监管

| 投资者类型 | 主要监管要求 |
|------------|-------------|
| 商业银行 | NFRA监管，需满足LCR、NSFR等流动性指标 |
| 证券公司 | 证监会监管，净资本管理 |
| 保险机构 | NFRA监管，偿付能力管理 |
| 基金公司 | 证监会监管，投资比例限制 |
| 理财子公司 | NFRA监管，理财产品投资范围限制 |
| 增外机构 | 外汇局+央行，投资额度与汇兑管理 |

## 三、重要政策法规

### 核心法律法规

| 法规 | 发布机构 | 核心内容 |
|------|----------|----------|
| 《中华人民共和国中国人民银行法》 | 全国人大 | 央行职能与权限 |
| 《中华人民共和国证券法》 | 全国人大 | 证券市场基本法律框架 |
| 《全国银行间债券市场债券交易管理办法》 | 央行 | 银行间债券市场交易规则 |
| 《银行间债券市场债券登记托管结算管理办法》 | 央行 | 托管结算规则 |
| 《关于规范金融机构资产管理业务的指导意见》 | 央行等 | 资管新规 |

### 近年来重要政策方向

1. **统一监管框架**
   - 债券市场基础设施互联互通
   - 统一公司信用类债券信息披露规则

2. **扩大开放**
   - 完善境外机构投资便利化
   - 推动中国债券纳入国际指数

3. **防范风险**
   - 加强信用风险预警与处置
   - 规范结构化发行
   - 完善违约处置机制

4. **金融科技**
   - 推动交易系统电子化升级
   - 探索区块链在债券领域的应用

## 四、对交易系统的影响

### 合规功能要求

1. **交易前合规**
   - 投资范围检查（品种、评级、发行人）
   - 集中度限制检查
   - 额度控制

2. **交易中监控**
   - 异常价格预警
   - 关联交易识别
   - 利益输送防范

3. **交易后报告**
   - 交易数据上报（CFETS/监管机构）
   - 持仓报告
   - 风险指标报告

### 系统设计考量

- 监管规则需可配置化，适应政策快速变化
- 需要完整的审计追踪（Audit Trail）
- 支持多维度合规报告生成
- 异常交易实时预警与拦截
