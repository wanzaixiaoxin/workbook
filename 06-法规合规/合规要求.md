## 二、交易前合规检查

### 1. 投资范围检查

| 检查项 | 说明 | 实现方式 |
|--------|------|----------|
| 债券品种限制 | 仅允许投资指定品种（如国债、政策性金融债等） | 品种白名单/黑名单 |
| 信用评级限制 | 最低评级要求（如AA+及以上） | 评级阈值配置 |
| 发行期限限制 | 投资组合的久期/期限限制 | 期限区间配置 |
| 发行主体限制 | 限制特定发行主体 | 主体名单管理 |
| 市场限制 | 限制银行间/交易所市场 | 市场标识过滤 |

### 2. 授信额度检查

| 检查项 | 说明 |
|--------|------|
| 交易对手授信 | 单一对手方交易额度上限 |
| 行业集中度 | 单一行业交易额度上限 |
| 集团集中度 | 同一集团下对手方合计额度上限 |
| 临时额度 | 临时调整的授信额度管理 |

### 3. 集中度限制

| 限制类型 | 说明 |
|----------|------|
| 单一债券持仓比例 | 持有同一债券占总资产的比例上限 |
| 单一发行人集中度 | 持有同一发行人所有债券的合计比例上限 |
| 交易对手集中度 | 与同一交易对手的交易量占比上限 |

### 4. 交易限额

| 限额类型 | 说明 |
|----------|------|
| 单笔交易限额 | 单笔交易金额上限 |
| 日累计限额 | 每日累计交易金额上限 |
| 止损限额 | 亏损达到阈值时限制交易 |
| 敞口限额 | 风险敞口（DV01、久期等）上限 |

### 5. 权限控制

| 控制维度 | 说明 |
|----------|------|
| 用户角色 | 交易员、复核员、管理员等角色权限 |
| 交易品种 | 不同角色可交易的品种范围 |
| 交易金额 | 不同角色的交易金额上限 |
| 操作权限 | 下单、撤销、修改等操作权限 |

## 三、交易中监控

### 1. 价格偏离监控

| 监控项 | 阈值参考 | 处理方式 |
|--------|----------|----------|
| 偏离估值 ±0.5% | 一级预警 | 弹窗提醒 |
| 偏离估值 ±1% | 二级预警 | 需确认后才能提交 |
| 偏离估值 ±2% | 三级预警 | 需主管审批 |

### 2. 异常行为监控

| 异常类型 | 说明 |
|----------|------|
| 频繁撤单 | 短时间内频繁撤销报价 |
| 虚假报价 | 报价后立即撤回，影响市场 |
| 对敲交易 | 与关联账户相互交易 |
| 尾盘操纵 | 收盘前异常交易影响收盘价 |
| 自买自卖 | 同一机构不同账户间交易 |

### 3. 关联交易识别

- 识别交易对手是否为关联方
- 关联交易需额外审批流程
- 定期生成关联交易报告

### 4. 实时敞口监控

| 指标 | 说明 |
|------|------|
| DV01 | 利率变动1bp对组合价值的影响 |
| 久期 | 组合的加权平均久期 |
| 凸性 | 组合的凸性指标 |
| VaR | 在险价值 |
| 流动性覆盖率 | 优质流动性资产/净现金流出 |

## 四、交易后管理

### 1. 数据报送

| 报送项 | 对象 | 内容 |
|--------|------|------|
| 成交数据 | CFETS | 交易要素、价格、数量 |
| 持仓变动 | 监管机构 | 持仓增减变动 |
| 大额交易 | 反洗钱中心 | 超额交易明细 |
| 异常交易 | CFETS/监管 | 异常交易说明 |

### 2. 审计追踪

所有操作需记录以下信息：

| 字段 | 说明 |
|------|------|
| 操作时间 | 精确到毫秒 |
| 操作用户 | 用户ID |
| 操作类型 | 下单/修改/撤销/审批等 |
| 操作内容 | 完整的操作参数 |
| 操作结果 | 成功/失败 |
| 操作终端 | IP地址、设备信息 |

### 3. 合规报告

| 报告类型 | 频率 | 内容 |
|----------|------|------|
| 日报 | 每日 | 交易汇总、持仓变动、风控指标 |
| 周报 | 每周 | 交易分析、异常汇总 |
| 月报 | 每月 | 合规统计、风险报告 |
| 季报 | 每季 | 综合风险管理报告 |

## 五、合规规则配置化

### 规则引擎设计

```
┌──────────────────────────────────────────┐
│              合规规则引擎                  │
│                                          │
│  ┌──────────┐  ┌──────────┐             │
│  │ 规则配置  │  │ 规则执行  │             │
│  │          │  │          │             │
│  │ 投资范围  │  │ 前置检查  │             │
│  │ 额度管理  │─▶│ 实时监控  │             │
│  │ 限额管理  │  │ 后置审计  │             │
│  │ 监控规则  │  │          │             │
│  └──────────┘  └──────────┘             │
│         │              │                 │
│         ▼              ▼                 │
│  ┌──────────┐  ┌──────────┐             │
│  │ 参数管理  │  │ 告警通知  │             │
│  │ 阈值配置  │  │ 日志记录  │             │
│  └──────────┘  └──────────┘             │
└──────────────────────────────────────────┘
```

### 配置化要求

1. **规则可配置**：合规规则可通过管理台配置，无需修改代码
2. **参数可调整**：阈值、限额等参数可实时调整并立即生效
3. **版本可追溯**：规则变更需记录变更历史
4. **支持灰度**：新规则可先在观察模式运行，不阻断交易
5. **多产品支持**：不同产品/账户可配置不同的合规规则
