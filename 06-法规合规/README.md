## 合规要点

银行间债券交易系统的合规要求贯穿交易全流程：

- **交易前**：投资范围限制、授信额度、集中度限制
- **交易中**：异常价格监控、交易行为监控
- **交易后**：数据报送、审计追踪、风险报告
