# 风控体系

> 最后更新：2026-03-30

## 一、债券交易风险类型

```
债券交易风险
├── 市场风险
│   ├── 利率风险 —— 利率变动导致债券价格波动
│   ├── 利差风险 —— 信用利差变动导致价格波动
│   ├── 汇率风险 —— 境外投资时的汇率波动
│   └── 流动性风险 —— 无法以合理价格及时买卖
│
├── 信用风险
│   ├── 违约风险 —— 发行人无法按时还本付息
│   ├── 交易对手风险 —— 交易对手无法履约
│   ├── 结算风险 —— 结算失败导致的损失
│   └── 评级下调风险 —— 信用评级下调导致价格下跌
│
├── 操作风险
│   ├── 交易操作失误 —— 误下单、价格错误等
│   ├── 系统故障 —— 交易系统宕机
│   ├── 流程风险 —— 内控流程不完善
│   └── 人员风险 —— 关键岗位人员变动
│
├── 合规风险
│   ├── 监管处罚 —— 违反监管规则
│   ├── 法律诉讼 —— 法律纠纷
│   └── 声誉风险 —— 负面事件影响声誉
│
└── 模型风险
    ├── 定价模型误差
    ├── 风险计量偏差
    └── 策略模型失效
```

## 二、风险度量指标

### 市场风险指标

| 指标 | 公式/说明 | 用途 |
|------|-----------|------|
| **DV01** | 利率变动1bp时，债券价值的变化金额 | 衡量利率敏感度 |
| **久期（Duration）** | 债券价格对利率变动的敏感度 | 衡量利率风险 |
| **修正久期** | 久期/(1+YTM/n) | 更精确的利率敏感度 |
| **凸性（Convexity）** | 久期对利率的变化率 | 利率大幅变动时的修正 |
| **VaR** | 在一定置信水平下的最大可能损失 | 综合市场风险度量 |
| **ES（CVaR）** | 超过VaR的平均损失 | 尾部风险度量 |

### 信用风险指标

| 指标 | 说明 |
|------|------|
| **信用评级** | 外部评级机构对发行人的评级 |
| **信用利差** | 债券收益率与无风险利率的差额 |
| **违约概率（PD）** | 发行人违约的概率 |
| **违约损失率（LGD）** | 违约时的预期损失比例 |
| **预期损失（EL）** | PD × LGD × EAD |

### 流动性风险指标

| 指标 | 说明 |
|------|------|
| **买卖价差（Bid-Ask Spread）** | 做市商买卖报价之差 |
| **日均成交量** | 债券的日均成交金额 |
| **换手率** | 日成交量/流通量 |
| **流动性覆盖率（LCR）** | 优质流动性资产/30天净现金流出 |
| **净稳定资金比率（NSFR）** | 可用稳定资金/所需稳定资金 |

## 四、关键风控算法

### DV01计算

```
DV01 = -ModifiedDuration × Price × FaceAmount / 10000

示例：
债券面值: 1亿
净价: 99.50
修正久期: 5.2年

DV01 = 5.2 × 99.50 × 100,000,000 / 10,000 = 5,174,000元

含义：利率上升1bp，该债券持仓亏损约5.17万元
```

### VaR计算方法

| 方法 | 说明 | 优缺点 |
|------|------|--------|
| **方差-协方差法** | 假设正态分布，用历史数据估计参数 | 计算快，但假设太强 |
| **历史模拟法** | 用历史场景直接模拟 | 无分布假设，但依赖历史 |
| **蒙特卡洛模拟** | 随机生成大量场景 | 最灵活，但计算量大 |

### 质押品充足率计算

```
质押品充足率 = 质押品市值 × 质押率 / 融资金额

要求：充足率 ≥ 100%

当充足率 < 100% 时触发追缴通知
```

## 五、风控系统设计原则

1. **实时性**：交易前合规检查需毫秒级响应，不影响交易效率
2. **准确性**：风险计算需精确，避免误报和漏报
3. **可配置性**：风控规则、阈值可灵活配置
4. **可扩展性**：支持新增风控规则和指标
5. **高可用性**：风控系统故障时，交易需按最严格规则执行（Fail-Safe）
6. **审计性**：所有风控检查结果需记录，支持事后审计
