│                       银行间债券交易全流程                            │

│  ┌──────────┐           ┌──────────────┐        ┌──────────────┐   │
│  │ 发行审批  │           │  询价/报价    │        │   交易确认    │   │

│  │ 缴款上市  │           │  交易确认    │        │   结算交割    │   │

### 以用户协作为主线理解业务流程

- **投资经理**：研判行情、确定标的与方向、给出数量与价格区间、跟踪成交后的组合影响
- **交易员**：接收指令、询价比价、选择成交路径、反馈执行结果、维护交易台账
- **中后台**：完成确认、清算结算、会计核算和监管报送
