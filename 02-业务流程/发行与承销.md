> 最后更新：2026-03-30

## 一、债券发行流程

### 总体流程

```
┌────────┐  ┌────────┐  ┌────────┐  ┌────────┐  ┌────────┐  ┌────────┐
│ 发行审批 │─▶│ 发行准备 │─▶│ 发行定价 │─▶│ 缴款上市 │─▶│ 登记托管 │─▶│ 交易流通 │
│ /注册   │  │ /推介   │  │ /簿记建档│  │        │  │        │  │        │
└────────┘  └────────┘  └────────┘  └────────┘  └────────┘  └────────┘
```

### 不同品种的发行方式

| 品种 | 审批方式 | 发行方式 | 主管机构 |
|------|----------|----------|----------|
| 国债 | 年度计划 | 招标发行 | 财政部 |
| 政策性金融债 | 央行审批 | 招标发行 | 政策性银行 |
| 非金融企业债务融资工具 | 交易商协会注册 | 簿记建档/招标 | NAFMII |
| 企业债 | 证监会/发改委审核 | 簿记建档 | 交易所 |
| 公司债 | 证监会注册 | 簿记建档 | 交易所 |
| 商业银行债 | NFRA+央行审批 | 簿记建档 | 银行 |

## 三、招标发行流程

主要用于国债和政策性金融债：

| 方式 | 说明 |
|------|------|
| **荷兰式招标（单一价格）** | 所有中标者统一按最低中标价格/最高中标利率成交 |
| **美式招标（多重价格）** | 各中标者按各自中标价格/利率成交 |
| **混合式招标** | 结合荷兰式和美式的特点 |

**招标流程**：
1. 财政部/发行人发布招标公告
2. 承销团成员通过系统提交投标
3. 系统自动汇总、排序、确定中标结果
4. 公布中标结果
5. 缴款、登记、上市

## 四、承销业务

### 承销团

- **主承销商**：负责组织承销团、簿记建档、定价配售
- **联席主承销商**：协助主承销商
- **分销商**：参与债券分销

### 承销商系统功能需求

| 功能 | 说明 |
|------|------|
| 招投标管理 | 支持多种招标方式，投标/中标管理 |
| 簿记建档 | 申购订单管理，定价配售 |
| 分销管理 | 分销额度管理，分销确认 |
| 缴款管理 | 缴款通知，缴款确认 |
| 上市管理 | 上市公告，流通安排 |

## 五、一级市场与二级市场联动

1. **一二级价差**：新债发行利率与二级市场收益率的差异影响申购积极性
2. **承销分仓**：主承销商可将承销额度分配给不同投资组合
3. **上市首日定价**：新债上市首日的定价参考发行利率与二级市场行情
4. **系统联动**：一级市场中标债券自动进入二级市场持仓管理
