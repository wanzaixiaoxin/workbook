# 交易品种

> 最后更新：2026-03-30

## 一、交易品种分类

银行间债券市场的交易品种可分为 **基础交易** 和 **衍生交易** 两大类。

```
交易品种
├── 基础交易
│   ├── 现券买卖
│   ├── 质押式回购
│   ├── 买断式回购
│   └── 债券借贷
│
└── 衍生交易
    ├── 债券远期
    ├── 利率互换（IRS）
    ├── 远期利率协议（FRA）
    └── 信用风险缓释工具（CRM）
```

## 二、基础交易品种详解

### 1. 现券买卖

**定义**：交易双方以约定的价格买卖一定数量的债券，在结算日进行券款交割。

| 要素 | 说明 |
|------|------|
| 交易标的 | 在银行间市场上市的各类债券 |
| 交易方式 | 询价交易、点击成交、请求报价 |
| 结算方式 | 券款对付（DVP）为主 |
| 结算周期 | T+0 或 T+1（可协商） |
| 最小交易单位 | 面值 10 万元 |
| 报价方式 | 净价报价（不含应计利息） |

**关键概念**：
- **净价**：债券价格不含应计利息
- **全价**：净价 + 应计利息
- **应计利息**：自上次付息日至结算日按天计算的利息
- **收益率**：到期收益率（YTM）是债券定价的核心指标

**交易场景**：
- 投资配置：长期持有获取票息收益
- 波段交易：通过利率变动获取价差收益
- 套利交易：利用一二级市场、不同品种间的价差套利

### 2. 质押式回购

**定义**：资金融入方将债券质押给资金融出方，约定在未来特定日期归还资金并解除质押。

| 要素 | 说明 |
|------|------|
| 交易标的 | 可用于质押的债券（按质押率折算） |
| 期限 | 1天~365天，以7天、14天为主 |
| 利率 | 回购利率（市场化定价） |
| 质押率 | 按债券信用等级设定（国债99%，信用债60%-90%） |
| 结算方式 | 首次结算：DVP；到期结算：资金返还+解押 |
| 交易占比 | 银行间市场交易量最大的品种 |

**关键指标**：
- **DR007**：存款类金融机构间的7天回购利率，是央行关注的核心利率指标
- **R007**：全市场7天回购利率（含非银）
- **质押率**：质押债券市值/融入资金金额

**回购利率的层级结构**：
```
DR001 < DR007 < DR014 < DR1M     （利率递增，期限越长期限溢价越高）
  ↑
R001 ≈ DR001（但波动更大）
```

### 3. 买断式回购

**定义**：资金融入方将债券卖给资金融出方，约定在未来特定日期按约定价格买回。

| 要素 | 说明 |
|------|------|
| 与质押式回购的区别 | 债券所有权发生转移 |
| 期限 | 1天~91天 |
| 用途 | 融资+融券（买断期间可用于再质押或卖出） |
| 市场占比 | 较小 |

### 4. 债券借贷

**定义**：债券融入方以一定数量的债券为质押，从债券融出方借入标的债券，约定在未来归还。

| 要素 | 说明 |
|------|------|
| 用途 | 做空、结算失败补救、套利 |
| 期限 | 1天~365天 |
| 费率 | 借贷费率（市场化定价） |
| 质押品 | 需提供足额质押债券 |

## 三、衍生交易品种详解

### 1. 利率互换（IRS）

**定义**：交易双方约定在未来一定期限内，根据约定数量的名义本金交换现金流（固定利率与浮动利率）。

| 要素 | 说明 |
|------|------|
| 参考利率 | FR007、Shibor3M、LPR1Y 等 |
| 期限 | 1M~10Y |
| 用途 | 利率风险管理、投机交易 |
| 清算方式 | 上清所集中清算 |

### 2. 债券远期

**定义**：交易双方约定在未来某一日期，以约定价格买卖一定数量的债券。

### 3. 信用风险缓释工具（CRM）

| 工具 | 说明 |
|------|------|
| CRMA（信用风险缓释合约） | 针对单一债务的信用保护 |
| CRMW（信用风险缓释凭证） | 标准化的信用保护凭证 |
| CLN（信用联结票据） | 嵌入信用风险的票据 |

## 四、各品种交易量对比（参考）

| 品种 | 日均交易量占比（约） | 说明 |
|------|---------------------|------|
| 质押式回购 | ~75% | 绝对主力 |
| 现券买卖 | ~18% | 第二大品种 |
| 买断式回购 | ~2% | 占比较小 |
| 同业存单 | ~3% | 含在现券统计中 |
| 债券借贷 | ~1% | 逐步增长 |
| 衍生品 | ~1% | 增长较快 |

> **注意**：以上为大致比例，具体数据请以 CFETS 公布的月度统计报告为准。

## 五、对交易系统的影响

1. **多品种支持**：系统需支持所有交易品种的下单、成交、结算
2. **差异化定价**：不同品种的计算逻辑不同（现券全价/净价、回购利息等）
3. **风险管理**：回购需管理质押品池，衍生品需管理保证金
4. **行情展示**：不同品种需展示不同的行情字段
5. **合规规则**：不同品种有不同的监管限制（如回购期限限制等）
