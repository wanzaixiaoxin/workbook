# 05 - 上下游生态

本模块梳理银行间债券交易系统的上下游生态，包括基础设施机构、数据服务商、技术合作方等。

## 文档索引

| 文档 | 说明 |
|------|------|
| [基础设施机构](./基础设施机构.md) | 交易平台、托管结算、支付清算等基础设施 |
| [数据服务商](./数据服务商.md) | 行情数据、估值数据、评级数据等数据来源 |
| [技术生态](./技术生态.md) | 技术组件、云服务、安全服务等技术合作方 |
