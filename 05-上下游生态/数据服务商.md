## 三、数据接入方式

### 接入技术方案

| 方式 | 适用场景 | 实时性 | 说明 |
|------|----------|--------|------|
| **API接口** | 行情、估值查询 | 实时 | REST/WebSocket |
| **SFTP文件** | 日终批量数据 | T+1 | 对账文件、持仓文件 |
| **数据库直连** | 大数据量查询 | 准实时 | 需网络互通 |
| **消息推送** | 实时行情 | 实时 | Kafka/MQ |
| **网页爬虫** | 公开数据 | 低频 | 仅限公开信息 |

## 四、数据标准化

### 债券编码体系

| 编码体系 | 说明 | 使用场景 |
|----------|------|----------|
| **CFETS代码** | CFETS内部债券代码 | 交易系统 |
| **CCDC代码** | 中债登债券代码 | 托管结算 |
| **SHCH代码** | 上清所债券代码 | 托管结算 |
| **ISIN** | 国际证券识别码 | 国际通用 |
| **Wind代码** | Wind债券代码 | 数据查询 |

> **系统设计要点**：需要建立统一的债券代码映射表，在不同编码体系之间进行转换。

### 数据质量要求

| 维度 | 要求 |
|------|------|
| **准确性** | 数据值准确无误 |
| **完整性** | 数据字段无缺失 |
| **及时性** | 实时数据延迟 < 3秒 |
| **一致性** | 多数据源之间保持一致 |
| **可追溯** | 数据变更可追踪 |
