# 基础设施机构

> 最后更新：2026-03-30

## 一、核心基础设施

### 1. 中国外汇交易中心（CFETS）

| 属性 | 说明 |
|------|------|
| **全称** | 中国外汇交易中心暨全国银行间同业拆借中心 |
| **隶属** | 中国人民银行直属事业单位 |
| **职能** | 银行间本外币市场的交易平台和信息服务机构 |
| **网址** | chinamoney.com.cn |

**与本系统的关系**：
- **交易通道**：所有交易必须通过CFETS系统执行
- **行情来源**：做市报价、成交行情数据的唯一来源
- **结算指令**：交易成交后自动生成结算指令
- **监管报送**：通过CFETS向央行报送交易数据

**CFETS提供的接口与工具**：
- 本币交易系统（CIBMTS）
- CFETS API（程序化交易接口）
- FIX/IMIX网关
- 行情数据接口（DataAPI）
- 交易后处理接口

**对接要求**：
- 需成为CFETS会员机构
- 需通过CFETS的接口认证测试
- 需使用CFETS指定的通信网络（专网/VPN）
- 需遵守CFETS的交易规则和接口规范

### 2. 中央结算公司（CCDC/中债登）

| 属性 | 说明 |
|------|------|
| **全称** | 中央国债登记结算有限责任公司 |
| **隶属** | 中国人民银行管理 |
| **职能** | 国债、金融债等债券的中央托管与结算 |
| **网址** | chinabond.com.cn |

**托管品种**：
- 国债
- 政策性金融债
- 商业银行债
- 企业债
- 地方政府债
- 资产支持证券（部分）

**结算服务**：
- 全额实时结算（RTGS）
- DVP结算
- 质押管理
- 付息兑付

**与本系统的关系**：
- **结算通道**：通过CCDC完成债券过户和资金划拨
- **估值数据**：中债估值是市场公认的债券估值基准
- **收益率曲线**：中债收益率曲线是市场定价基准
- **持仓数据**：通过CCDC查询债券持仓余额

**接口方式**：
- 直连接口（专线）
- 文件传输（SFTP）
- Web服务

### 3. 银行间市场清算所（SHCH/上清所）

| 属性 | 说明 |
|------|------|
| **全称** | 银行间市场清算所股份有限公司 |
| **隶属** | 中国人民银行管理 |
| **职能** | 短融中票等债券的托管结算，衍生品集中清算 |
| **网址** | shclearing.com |

**托管品种**：
- 短期融资券（CP）
- 超短期融资券（SCP）
- 中期票据（MTN）
- 同业存单（NCD）
- 资产支持票据（ABN）
- 信用风险缓释工具

**清算服务**：
- 全额结算
- 集中净额结算（衍生品）
- 保证金管理

**与本系统的关系**：
- **结算通道**：短融、中票等品种通过SHCH结算
- **集中清算**：利率互换等衍生品通过SHCH集中清算
- **保证金管理**：集中清算品种需管理保证金

### 4. 中国人民银行支付系统

| 系统 | 说明 |
|------|------|
| **HVPS（大额支付系统）** | 实时全额结算，处理大额资金划拨 |
| **BEPS（小额支付系统）** | 批量净额结算 |
| **CNAPS** | 中国现代化支付系统（HVPS+BEPS的统称） |
| **CIPS** | 人民币跨境支付系统 |

**与本系统的关系**：
- DVP结算中的资金划拨通过央行支付系统完成
- 需确保交易系统与支付系统的时序协调

## 二、交易所市场基础设施

| 机构 | 职能 | 与本系统的关系 |
|------|------|---------------|
| **上交所（SSE）** | 交易所债券市场交易与监管 | 跨市场交易时需对接 |
| **深交所（SZSE）** | 交易所债券市场交易与监管 | 跨市场交易时需对接 |
| **中证登（CSDC）** | 交易所债券市场托管结算 | 跨市场转托管时需对接 |

## 三、自律组织

| 组织 | 职能 |
|------|------|
| **NAFMII（交易商协会）** | 非金融企业债务融资工具注册管理、市场自律 |
| **CFA（中国金融学会）** | 学术研究、行业交流 |

## 四、对接矩阵

| 基础设施 | 接入方式 | 数据流向 | 对接优先级 |
|----------|----------|----------|-----------|
| CFETS | API/FIX/IMIX | 双向 | P0 |
| CCDC | 直连/SFTP | 双向 | P0 |
| SHCH | 直连/SFTP | 双向 | P0 |
| 央行HVPS | 间接（通过CCDC/SHCH） | 资金划拨 | P1 |
| 上交所/深交所 | 接口/文件 | 双向（跨市场时） | P2 |
| 中证登 | 接口/文件 | 双向（跨市场时） | P2 |
