# 03 - 系统架构

本模块描述银行间债券交易系统的产品形态、功能架构、技术架构与接口规范，并以固收投资经理和交易员的核心工作流为主线，为产品设计与技术实现提供参考。

## 核心用户导向

| 用户 | 对系统的核心诉求 | 对架构的直接要求 |
|------|----------------|----------------|
| 固收投资经理 | 看得清、下得准、跟得上 | 组合管理、行情分析、指令管理、成交反馈必须形成闭环 |
| 交易员 | 找得到、谈得快、成得稳、留得全 | 询报价工作台、对手管理、交易执行、合规留痕必须高频高效 |

## 当前产品形态摘要

结合《终端白皮书_1126》，当前产品更适合被描述为“前台债券终端 + 债券工作台 + AI/NLP 能力层”的组合，而不是单一的下单系统。

- **行情系统（MS）**：承接公共行情、报价、监控和多屏展示
- **分析系统（AS）**：承接市场分析、信用分析、利率分析和定价研究
- **债券工作台**：承接任务、私域行情、议价、群发、单据管理等交易协同动作
- **AI/NLP 能力层**：承接聊天语义解析、要素抽取、多轮上下文关联和合规留痕

## 系统定位

银行间债券交易系统是金融机构参与银行间债券市场的核心业务系统。结合当前产品落地形态，它既承担行情获取、投资决策支持、交易协同和合规留痕，也通过工作台与下游交易系统衔接，形成从前台终端到成交落地的业务闭环。
