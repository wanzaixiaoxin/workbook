# 03 - 系统架构

本模块描述银行间债券交易系统的功能架构、技术架构与接口规范，并以固收投资经理和交易员的核心工作流为主线，为产品设计与技术实现提供参考。

## 核心用户导向

| 用户 | 对系统的核心诉求 | 对架构的直接要求 |
|------|----------------|----------------|
| 固收投资经理 | 看得清、下得准、跟得上 | 组合管理、行情分析、指令管理、成交反馈必须形成闭环 |
| 交易员 | 找得到、谈得快、成得稳、留得全 | 询报价工作台、对手管理、交易执行、合规留痕必须高频高效 |

## 系统定位

银行间债券交易系统是金融机构参与银行间债券市场的核心业务系统，承担从行情获取、投资决策支持、交易执行、合规风控到清算结算的全流程业务处理。
