## 二、核心功能模块详解

### 1. 行情中心

| 功能 | 说明 | 优先级 |
|------|------|--------|
| **实时行情** | 做市商双边报价、最优报价、市场深度 | P0 |
| **成交行情** | 最新成交价、成交量、成交笔数 | P0 |
| **收益率曲线** | 国债/政策性金融债收益率曲线展示 | P0 |
| **债券估值** | 中债估值、上清所估值查询 | P0 |
| **历史行情** | 历史成交数据查询与图表分析 | P1 |
| **市场资讯** | 财经新闻、公告、研究报告集成 | P2 |
| **自选管理** | 自选债券列表、自定义监控条件 | P1 |
| **报价矩阵** | 按期限/评级展示做市报价矩阵 | P1 |

### 2. 交易中心

#### 2.1 现券交易

| 功能 | 说明 | 优先级 |
|------|------|--------|
| **询价交易** | RFQ发送、报价回复、多轮谈判 | P0 |
| **点击成交** | 接受做市商报价即时成交 | P0 |
| **对话报价** | 一对一即时通讯+报价协商 | P0 |
| **意向报价** | 发布买卖意向，等待对手方联系 | P1 |
| **匿名交易** | 匿名报价，成交后揭示对手 | P2 |

#### 2.2 回购交易

| 功能 | 说明 | 优先级 |
|------|------|--------|
| **质押式回购** | 正回购/逆回购报价与成交 | P0 |
| **买断式回购** | 买断式回购交易 | P1 |
| **质押品自动筛选** | 根据质押率自动筛选最优质押券组合 | P0 |
| **回购续做** | 到期自动/手动续做 | P1 |

#### 2.3 做市管理

| 功能 | 说明 | 优先级 |
|------|------|--------|
| **双边报价** | 持续发布买入/卖出双边报价 | P0 |
| **报价策略** | 基于库存和风险的自动报价策略 | P1 |
| **报价监控** | 报价状态、点击成交监控 | P0 |
| **做市统计** | 做市成交量、价差统计 | P1 |

#### 2.4 策略交易

| 功能 | 说明 | 优先级 |
|------|------|--------|
| **利差交易** | 跨品种/跨期限利差交易 | P2 |
| **蝶式交易** | 三只债券的蝶式套利 | P2 |
| **骑乘策略** | 收益率曲线骑乘策略执行 | P2 |
| **算法执行** | TWAP/VWAP 算法拆单 | P2 |

### 3. 风控中心

| 功能 | 说明 | 优先级 |
|------|------|--------|
| **交易前合规** | 投资范围、集中度、额度实时检查 | P0 |
| **授信管理** | 交易对手授信额度管理 | P0 |
| **价格监控** | 异常价格预警（偏离估值阈值） | P0 |
| **敞口监控** | 实时持仓、久期、DV01 监控 | P0 |
| **限额管理** | 交易限额、持仓限额、止损限额 | P0 |
| **关联交易** | 关联方交易识别与预警 | P1 |
| **异常行为** | 异常交易行为监控与预警 | P1 |
| **风险报告** | 日/周/月度风险管理报告 | P1 |

### 4. 结算中心

| 功能 | 说明 | 优先级 |
|------|------|--------|
| **结算指令** | 自动生成/手工录入结算指令 | P0 |
| **指令匹配** | 与对手方结算指令匹配 | P0 |
| **清算计算** | 全价/利息/结算金额计算 | P0 |
| **结算跟踪** | 结算状态实时跟踪 | P0 |
| **对账管理** | 与托管机构、交易对手日终对账 | P0 |
| **资金管理** | 资金头寸管理、资金调拨 | P1 |
| **会计核算** | 交易会计分录生成 | P1 |
| **结算失败处理** | 结算失败的异常处理流程 | P1 |

### 5. 质押品管理

| 功能 | 说明 | 优先级 |
|------|------|--------|
| **质押券池管理** | 可质押债券的统一管理 | P0 |
| **质押率维护** | 按品种/评级的质押率配置 | P0 |
| **自动筛选** | 最优质押券组合的自动计算 | P0 |
| **质押品替换** | 存续期间质押品的替换操作 | P1 |
| **逐日盯市** | 质押品市值逐日重新计算 | P0 |
| **追缴通知** | 质押品不足时的追缴通知 | P1 |

### 6. 系统管理

| 功能 | 说明 | 优先级 |
|------|------|--------|
| **用户管理** | 用户账号、角色、权限管理 | P0 |
| **参数配置** | 系统参数、业务规则配置 | P0 |
| **日志管理** | 操作日志、系统日志查询 | P0 |
| **接口管理** | 外部接口状态监控 | P0 |
| **系统监控** | 系统性能、健康状态监控 | P1 |
| **数据备份** | 数据备份与恢复 | P1 |

## 三、功能优先级规划

### P0 - 核心功能（首期必须）

```
行情中心: 实时行情、成交行情、收益率曲线、债券估值
交易中心: 现券询价/点击成交、质押式回购、做市报价
风控中心: 交易前合规、授信管理、价格监控、敞口监控、限额管理
结算中心: 结算指令、指令匹配、清算计算、结算跟踪、对账
质押品管理: 质押券池、质押率、自动筛选、逐日盯市
```

### P1 - 增强功能（二期）

```
行情中心: 历史行情、自选管理、报价矩阵
交易中心: 债券借贷、回购续做、做市统计
风控中心: 关联交易、异常行为、风险报告
结算中心: 资金管理、会计核算、结算失败处理
```

### P2 - 高级功能（远期）

```
行情中心: 市场资讯、智能推荐
交易中心: 衍生品交易、策略交易、算法执行
风控中心: 智能风控、预测性风险预警
```
