### 角色目标与成功标准

| 角色 | 系统核心价值 | 高频模块 | 关键结果 |
|------|--------------|----------|----------|
| 投资经理 | 帮助更快形成决策、清晰下达指令、及时感知成交后的组合变化 | 行情中心、指令管理、组合管理、风控审批 | 指令表达准确、组合影响可见、成交反馈及时 |
| 交易员 | 帮助更快询价、比价、成交，并完整保留沟通与执行链路 | 询报价工作台、交易中心、成交反馈、合规留痕 | 执行效率高、成交价格优、留痕完整 |

### 用户核心操作路径

**投资经理典型路径**：
```
登录 → 查看组合概览 → 研判行情 → 下达交易指令 → 跟踪指令执行 → 确认成交 → 组合监控
```

**交易员典型路径**：
```
登录 → 接收指令池 → 查看行情/做市报价 → IM询价(QTrade/iDeal) → 达成意向
     → AI台账记录 → CFETS成交 → 反馈成交结果 → 管理交易台账
```

### 架构设计原则

1. **决策与执行分离**：投资经理负责交易意图、价格区间和组合约束，交易员负责执行路径与成交落地
2. **前台闭环优先**：行情、指令、询价、成交和反馈必须形成同一条可追踪链路
3. **合规前置**：合规校验应嵌入指令下达、询报价和成交环节，而不是依赖事后补录
4. **留痕贯穿全流程**：沟通记录、交易意向、成交单、确认单和结算指令之间应可关联追踪

## 三、核心功能模块详解

### 1. 行情中心

| 功能 | 说明 | 优先级 |
|------|------|--------|
| **实时行情** | 做市商双边报价、最优报价、市场深度 | P0 |
| **成交行情** | 最新成交价、成交量、成交笔数 | P0 |
| **收益率曲线** | 国债/政策性金融债收益率曲线展示 | P0 |
| **债券估值** | 中债估值、上清所估值查询 | P0 |
| **历史行情** | 历史成交数据查询与图表分析 | P1 |
| **市场资讯** | 财经新闻、公告、研究报告集成 | P2 |
| **自选管理** | 自选债券列表、自定义监控条件 | P1 |
| **报价矩阵** | 按期限/评级展示做市报价矩阵 | P1 |

### 2. 交易中心

> 交易中心是投资经理与交易员协作最密集的模块，需同时支持“指令驱动成交”和“询报价驱动成交”两条路径。

#### 2.1 现券交易

| 功能 | 说明 | 优先级 |
|------|------|--------|
| **询价交易** | RFQ发送、报价回复、多轮谈判 | P0 |
| **点击成交** | 接受做市商报价即时成交 | P0 |
| **对话报价** | 一对一即时通讯+报价协商 | P0 |
| **意向报价** | 发布买卖意向，等待对手方联系 | P1 |
| **匿名交易** | 匿名报价，成交后揭示对手 | P2 |

#### 2.2 询报价与交易意向管理（核心子模块）

> 这是银行间债券交易系统的差异化核心模块，直接对应约80%的交易达成路径。

| 功能 | 说明 | 优先级 |
|------|------|--------|
| **IM消息接入** | 对接QTrade/iDeal，获取交易沟通记录 | P0 |
| **AI语义识别** | 从非结构化聊天中提取债券代码、价格、数量、意图 | P0 |
| **交易意向台账** | 自动汇总当日成交意向，结构化展示 | P0 |
| **台账模板导出** | 支持恒生O32/O45、衡泰xIR格式导出 | P0 |
| **意向指令下达** | 交易意向直连内部投资交易系统（恒生/衡泰） | P1 |
| **多IM统一管理** | 统一管理QTrade/iDeal等多渠道询价 | P1 |
| **报价看板** | 实时展示多对手方报价对比面板 | P1 |
| **询价广播** | 向多个对手方同时发送询价请求 | P1 |
| **意向→成交闭环** | 从IM意向到CFETS成交单的全链路追踪 | P0 |
| **改标/撤标管理** | 支持一级投标的改标、撤标操作跟踪 | P1 |
| **合规留痕** | 交易沟通全量记录，满足交易商协会监管要求 | P0 |

## 四、功能优先级规划

### P0 - 核心功能（首期必须）

```
行情中心: 实时行情、成交行情、收益率曲线、债券估值
交易中心: 现券询价/点击成交、询报价与交易意向管理、质押式回购、做市报价
风控中心: 交易前合规、授信管理、价格监控、敞口监控、限额管理
结算中心: 结算指令、指令匹配、清算计算、结算跟踪、对账
质押品管理: 质押券池、质押率、自动筛选、逐日盯市
```

### P1 - 增强功能（二期）

```
行情中心: 历史行情、自选管理、报价矩阵
交易中心: 债券借贷、回购续做、做市统计
风控中心: 关联交易、异常行为、风险报告
结算中心: 资金管理、会计核算、结算失败处理
```

### P2 - 高级功能（远期）

```
行情中心: 市场资讯、智能推荐
交易中心: 衍生品交易、策略交易、算法执行
风控中心: 智能风控、预测性风险预警
```
