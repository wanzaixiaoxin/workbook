# 银行间债券交易系统 - 知识库

## 项目定位

本项目知识库服务于银行间债券交易系统的产品研发团队，旨在系统化地收集、整理和共享以下领域的知识：

- **市场认知**：银行间债券市场的运行机制、参与主体与发展趋势
- **业务理解**：债券交易的完整业务链路，从询价到清算结算
- **系统设计**：交易系统的功能架构、技术架构与接口规范
- **竞争格局**：主要竞品的产品形态与差异化分析
- **生态全景**：上下游基础设施、数据服务商与合作方网络
- **合规风控**：法律法规框架与风险控制体系

## 知识库使用指南

### 面向角色

- **产品经理**：重点阅读「市场概述」「竞品分析」「业务流程」，理解市场需求与产品定位
- **业务分析师**：重点阅读「业务流程」「法规合规」，掌握交易业务细节与合规要求
- **架构师**：重点阅读「系统架构」「上下游生态」，理解技术架构与系统集成
- **开发工程师**：重点阅读「系统架构」「业务流程」，理解功能需求与实现方式
- **测试工程师**：重点阅读「业务流程」「系统架构」，理解测试场景与验收标准

### 文档规范

1. 所有文档使用 Markdown 格式编写
2. 每个目录下包含 `README.md` 作为模块索引
3. 文档中涉及的数据需标注来源和更新时间
4. 重要结论需标注依据，保持可追溯性
